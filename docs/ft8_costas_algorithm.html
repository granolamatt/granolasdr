1  FT8 Frame Structure (79 symbols)

Costas sync symbol (with tone dot = expected bin) Data / message symbol

Three identical Costas groups at symbol positions 0–6, 36–42, and 72–78. The kernel indexes them as block_abs = time_off + 36×m + k (m = 0,1,2  ·  k = 0..6).

2  Costas Tone Pattern — kCostas[7] = {3, 1, 4, 0, 6, 5, 2}

Symbol index k →

Each Costas symbol k transmits on a single 8-FSK tone bin sm = kCostas[k] (0–7 within the 8-tone group). The pattern forms a Costas array — no two symbols share a row, column, or diagonal, making it easy to distinguish from noise even at low SNR.

static __constant__ uint8_t kCostas[7] = {3, 1, 4, 0, 6, 5, 2}; // tone bin per symbol

// per symbol k:
int sm = kCostas[k]; // expected freq bin (0–6)
int si = (m*7+k) * WINDOW + threadIdx.x; // smem base
int cur = smem[si + sm]; // magnitude at Costas bin

For each of 21 symbols (m=0..2, k=0..6):
sm  =kCostas[k] expected tone bin within 8-FSK group
cur =smem[slot + sm] magnitude at expected Costas bin
score += (sm>0) cur − smem[slot + sm−1]   // freq below += (sm<7) cur − smem[slot + sm+1]     // freq above += (k>0) cur − smem[prev_slot + sm]   // time back += (k<6) cur − smem[next_slot + sm]   // time fwd
score /=num_avg normalize by number of valid comparisons
Emit if score ≥ min_score → write (fo, time_off, time_sub, freq_sub, score) via atomicAdd
Intuition: Score measures how much the expected Costas tone stands out from its immediate frequency and temporal neighbors. A clean signal gives large positive differences; noise gives near-zero. Dividing by num_avg normalizes partial Costas groups at the frame edges.

4  Shared Memory Layout — 21 × WINDOW bytes

WINDOW = blockDim.x + 8 = 264 bytes per slot (only first ~11 shown here; total is 264). The highlighted cell is the Costas tone bin for that slot. Threads load cooperatively in stride-blockDim.x pattern so all loads are contiguous (coalesced). Score computation then reads entirely from smem — no further global memory accesses.
