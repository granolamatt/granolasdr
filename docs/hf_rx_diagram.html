CUDA THREAD HFChannelizer gm/cuda/HFChannelizer.cc
Processing steps
  • Cast int16_t → float, copy to GPU
  • Overlap input by one slot for continuity
  • Wideband R2C FFT: 1,048,576 points (cuFFT)
  • Zero composite IFFT buffer
  • Copy 10 HF band slices into composite buffer
  • Inverse C2C FFT: 32,768 points
  • Extract center half (16,384 samples), async copy to ring

CUDA THREAD FT8Cuda — Oversampled Waterfall gm/cuda/FT8Cuda.cc
Processing steps
  • Accumulate input slots into GPU sliding window
  • When window > 2 × rfft_length samples:
  • 9× oversampled C2C FFT: 698,880 pts each,
    offsets at t × rfft_length/9 (time supersampling)
  • magKernel: complex → dB-scaled uint8_t
  • Async copy to rolling ring slot (host RAM)
  • Slide window back by rfft_length
  • Every 15 s (trigger == second 14 of cycle):
  • cudaStreamSynchronize
  • Background thread: copy last 106 ring blocks → decode slot, signal decoder

uint8_t waterfall · 4 decode slots × 106 blocks × 9 sub-times × 698,880 bins · host RAM
CPU THREAD FT8 Decoder gm/hf/ft8.cc · ft8_lib/
Processing steps
  • memcpy decode slot → monitor_t waterfall
  • Parallel candidate search — N CPU threads, each searches a frequency slice:
  • Costas sync score across time_offset 0–29 and all freq bins
  • ftx_find_candidates_range() (custom range variant)
  • Merge per-thread heaps, sort by score, cap at 2,000
  • Parallel LDPC decode — N threads, round-robin over candidates:
  • 25 iterations, soft-decision
  • ftx_decode_candidate()
  • Sequential dedup by 22-bit message hash
  • Unpack callsign/grid/report via ftx_message_decode()
  • Print DECODED: line, compute RF frequency
  • Publish JSON to ZMQ PUB socket
  • Age callsign hashtable, reset waterfall
