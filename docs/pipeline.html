granolasdr Signal Processing Pipeline

RX888 → HFChannelizer → MagBlock → FT8Cuda/JS8Cuda → ft8.cc/js8.cc → ZMQ proxy | block diagram with code locations
RX888 ADC hw thread gm/rx888/rx888.h
116-bit real ADC samples, 140 MS/s
2DMA into host ring buffer, block = 524,288 samples = 3.75 ms
3Signals BufferPosition<int16_t> — HFChannelizer thread wakes
Playback mode (--playback FILE): BufferFile<complex<float>> reads a .dat file and feeds BufferPosition<complex<float>> directly into runPipeline — bypasses RX888 and HFChannelizer.
int16_t ring · 140 MS/s · 524,288 samples/block
HFChannelizer — Wideband FFT & Band Select CUDA thread gm/cuda/HFChannelizer.cc
1H2D copy: int16 → GPU
2Cast kernel: int16 → float32, scale
3Overlap-save wrap: copy tail of previous block to start of fftInData_d
4 R2C FFT: 1,048,576-pt real → complex
bin width = 140,000,000 / 1,048,576 ≈ 133.5 Hz/bin
output: 524,288 complex bins spanning 0–70 MHz
5 Band bin select: zero-fill channelData_d[32768], then copy 10 HF bands:
160m 13480–14980 80m 26212–29960 60m 39920–40712 40m 52424–54676 30m 75644–76024 20m 104856–107480 17m 135324–136076 15m 157284–160660 12m 186420–187172 10m 209712–222448
6 C2C IFFT: 32,768-pt composite → decimated time domain
output rate = 140,000,000 / 32 = 4,375,000 S/s
7 Overlap-save extract: samples [8192..24576] = 16,384 complex → ring
Record mode (--record FILE): BufferFile<complex<float>> taps this ring and writes to disk with block timing metadata for deterministic replay.
complex<float> ring · 4.375 MS/s · 16,384 samples/block · all HF bands packed
MagBlock — Oversampled FFT & Magnitude Ring CUDA thread gm/cuda/MagBlock.cc
1 Accumulate: D2D copy blocks → window until buff_pos > 2 × 698,880 = 1,397,760 samples
≈ 85 HFChannelizer blocks = 320 ms of data
2 16 FFTs (4 time offsets × 4 freq offsets):
time offset t=0..3start sample = t × 174,720
freq offset f=0..3freqShift by f × 1.5625 Hz
each FFTC2C 698,880-pt → 698,880 bins
bin width4,375,000 / 698,880 = 6.25 Hz (1 FT8 tone)
3 Advance: buff_pos -= 698,880 samples
= 160 ms = one FT8 symbol period → fires ~6.25×/sec
4 magKernel: complex → uint8 magnitude
each byte ≈ 20·log₁₀(|z|) + offset (dB-compressed power)
5 D2D ring write: 1 block = 4×4×698,880 = 11,182,080 bytes → DeviceRingBuffer
ring wraps at N=200 slots = 2.24 GB on GPU
Ring memory layout:
mag[block × block_stride + (ts×4 + fs) × 698880 + fo]
block_stride = 4×4×698,880 = 11,182,080 bytes
ts = time sub-sample [0..3] | fs = freq sub-sample [0..3] | fo = freq bin [0..698879]
6 Wideband waterfall: → ZMQ proxy topic ft8/waterfall
FT8Cuda and JS8Cuda both hold const& DeviceRingBuffer — no second FFT needed. MagBlock owns the ring memory; scanners hold references.
FT8Cuda — Continuous Scan CUDA thread FT8Cuda.cc · FT8ScanCuda.cu
1 Wakes every 6 blocks (~960 ms)
stride = 6; reads last 106 blocks (16.93 s) from DeviceRingBuffer
2 ft8SyncScanKernel (FT8ScanCuda.cu):
Costas pattern {3,1,4,0,6,5,2} at 3 sync groups
score ≥ min_score → candidate list (fo, to, ts, fs)
3 ft8_soft_symbols_kernel (FT8SoftCuda.cu):
58 data syms × 8 mag bins → 3 LLRs/sym (Gray-coded 8-FSK)
output: log174_d (n × 174 floats)
4 D2H candidates + log174 → decode callback
callback = FT8::decodeAndPublishContinuous() (wired in FT8 constructor)
JS8Cuda — Continuous Scan CUDA thread (--js8) JS8Cuda.cc
1 Reads same DeviceRingBuffer (no second FFT)
JS8 epoch = 15 s; continuous scan shares MagBlock ring
2 JS8 Costas scan kernel:
Costas pattern {4,2,5,6,1,3,0}
score ≥ min_score → candidate list
3 Soft symbol kernel:
LDPC code (174,91), M=87
output: log174_d per candidate
4 D2H → decode callback
callback = JS8::decodeAndPublishContinuous() (wired in JS8 constructor)
decode callback · candidates + log174 (174 floats/cand · ~15 MB typical)
ft8.cc — 15s Window Decoder CPU thread gm/hf/ft8.cc · ft8_lib/
1 LDPC decode: ftx_decode_from_llr()
normalize GPU LLRs · 25-iter BP · (174,91) code · 14-bit CRC
2 Message unpack: 77 bits → callsign1 + callsign2 + grid/report
3 window_buf_ accumulate: best-SNR per callsign
hash_if: callsign hash → window_buf_ key; keep highest score entry
4 flushWindow() every 15 s:
print "[FT8] 15s window: N unique callsigns"
publishDecoded() → ZMQ PUSH to proxy (topic: ft8/decode)
hashtable_cleanup(10): age callsign hash entries
5 RF freq: composite_bin_to_rf_hz() → kBandMap (from kHFBands)
js8.cc — Epoch Decoder CPU thread (--js8) gm/hf/js8.cc · ft8_lib/
1 LDPC decode: BP decoder
(174,91) code M=87 · CRC-12 check
2 JSC decompress: Huffman decode
JS8Call JSC bitstream → UTF-8 text
3 Frame decode: Normal/Compact/Ultra/Turbo
extracts from_call, to_call, message text, APRS fields
4 Per-epoch dedup: seen_this_epoch_ set
cleared when floor(unix/15) rolls over
5 publishDecoded() → ZMQ proxy (topic: js8/decode)
ZMQ proxy XSUB:5599 ← producers | XPUB:5600 → consumers · topics: ft8/decode js8/decode
ZMQ Proxy Bus + PSKReporter proxy thread + Python HFRx.cc runProxy() · psk_uploader.py
1 XSUB :5599 ← FT8, JS8, MagBlock waterfall connect here
2 XPUB :5600 → subscribers connect here and filter by topic
3 ft8/decode JSON example:
{"call":"WA9TT","freq":7076397,"snr":-7.0,"unix":…,"offset":3.0}
4 psk_uploader.py: subscribes to :5600
filters ft8/ and js8/ topics
per-band best-SNR dedup · IPFIX UDP → pskreporter.info:4739 every 5 min
