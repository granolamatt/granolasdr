granolasdr Signal Processing Pipeline

RX888 → HFChannelizer + SpectrumNorm → MagBlock → FT8Cuda/JS8Cuda/WaterfallCuda → ft8.cc/js8.cc → ZMQ + wsdict
RX888 ADC hw thread gm/rx888/rx888.h
116-bit real ADC samples, 140 MS/s
2DMA into host ring buffer, block = 700,000 samples = 5 ms
3Signals BufferPosition<int16_t> — HFChannelizer thread wakes
Playback mode (--playback FILE): BufferFile<complex<float>> reads a .dat file and feeds BufferPosition<complex<float>> directly — bypasses RX888 and HFChannelizer.
int16_t ring · 140 MS/s · 700,000 samples/block
HFChannelizer — Wideband FFT, Band Select & Audio CUDA thread gm/cuda/HFChannelizer.cc
1H2D copy + cast: int16 → float32
2Overlap-save wrap: copy tail to head of fftInData_d
3 R2C FFT: 1,400,000-pt
bin width = 140 MHz / 1,400,000 = 100 Hz/bin
output: 700,001 bins spanning 0–70 MHz
4 Audio extraction: 4 sinks
480-bin gather per sink → batched C2C IFFT → 48 kHz ZMQ PUB :5581–5584
sink_bins[] tunable at runtime via wsdict granolasdr:audio:cmd
5 11-band composite: zero channelData_d[4096], copy 11 bands:
160m 70 bins 80m 100 bins 60m 180 bins 40m 140 bins 30m 130 bins 20m 300 bins 17m 430 bins 15m 230 bins 12m 170 bins 10m 270 bins 6m 90 bins
total composite: 2110 bins of 4096
6 C2C IFFT: 4096-pt → decimated time domain
extract center half: 2048 valid samples → ring
output rate = 409.6 kHz, block period = 5 ms
Record mode (--record FILE): BufferFile<complex<float>> taps this ring for deterministic replay.
complex<float> ring · 409.6 kHz · 2048 samples/block · 11 HF bands packed
SpectrumNorm — Noise Floor Equalization in HFChannelizer (every 64 frames) gm/cuda/SpectrumNorm.cu
1 D2H snapshot: copy 2110 complex bins from fftData_d
one snapshot per band window every ~10 s at 6.25 Hz frame rate
2 Asymmetric EMA of |mag| per bin:
α_down = 0.10 (warm) — tracks fast signal drops
α_up = 0.005 (warm) — drifts up slowly (~30 min time constant)
warm-up: α_down=0.30, α_up=0.10 for first 5 updates
3 Legendre poly fit (degree 3) on log10(EMA) per band
gains[i] = 10^(poly_center − poly(xi)) → flattens noise floor to band center
4 Cross-band leveling: geometric mean of 11 band-center EMAs
per-band scalar brings all bands to the same brightness
5 H2D gain upload → GPU kernel multiplies channelData_d in-place (before IFFT)
complex<float> ring · 409.6 kHz · 11 bands spectrally equalized
MagBlock<200> — Oversampled FFT & Magnitude Ring (Normal) CUDA thread gm/cuda/MagBlock.cc
1 Accumulate: blocks until window ≥ 2 × 65,536 samples (~320 ms)
2 16 FFTs (4 time offsets × 4 freq offsets):
each FFTC2C 65,536-pt
bin width409,600 / 65,536 = 6.25 Hz (1 FT8 tone)
block duration160 ms = 1 FT8 symbol
3 magKernel: complex → uint8 (dB-compressed power)
4 D2D ring write: DeviceRingBuffer<uint8_t, 200>
block = 4×4×65,536 = 1,048,576 bytes · ring ≈ 200 MB VRAM
5 Slide: advance by 65,536 samples → fires at 6.25 Hz
FT8Cuda, JS8Cuda, WaterfallCuda all hold const& to this ring
WaterfallCuda gm/cuda/WaterfallCuda.cc
1 Reads DeviceRingBuffer (same normal ring)
wf_bin_start/end configurable via --waterfall-* flags
2 waterfallKernel: uint8 power → RGBA colormap
wf_floor=170, wf_ceil=210 (configurable)
2048-col output per row
3 D2H RGBA batch → wsdict
key: granolasdr:waterfall:N
browser renders to canvas via WebSocket
FT8Cuda — Continuous Scan FT8Cuda.cc · FT8ScanCuda.cu
1 Wakes every 6 blocks (~960 ms)
reads last 106 blocks (16.9 s) from DeviceRingBuffer
2 Costas scan kernel:
max-log 8-FSK metric (or legacy freq+neighbor)
Costas {4,2,5,6,1,3,0} · score ≥ min_score
→ candidate list (fo, to, ts, fs)
3 Soft symbol kernel:
58 data syms × 8 bins → 3 LLRs/sym (Gray-coded)
output: log174 (174 floats/cand)
4 D2H → FT8::decodeAndPublishContinuous()
JS8Cuda — Continuous Scan JS8Cuda.cc (--js8)
1 Same DeviceRingBuffer as FT8Cuda (no extra FFT)
All modes: 108-blk window (cap_blocks = max_block_abs+1 = 108)
2 JS8 Costas scan kernel:
Costas {4,2,5,6,1,3,0} (Normal/Slow)
score ≥ min_score → candidate list
3 Soft symbol kernel:
LDPC (174,87) · CRC-12
output: log174 per candidate
4 D2H → JS8::decodeAndPublishContinuous()
decode callbacks · candidates + log174 (174 floats/cand)
ft8.cc — 15s Window Decoder CPU thread gm/hf/ft8.cc · ft8_lib/
1 LDPC decode: ftx_decode_from_llr()
normalize GPU LLRs · 25-iter BP · (174,91) code · CRC-14
2 Message unpack: 77 bits → callsign1, callsign2, grid/report
3 window_buf_ accumulate: best-SNR per callsign over 15 s
4 flushWindow() every 15 s:
ZMQ: topic ft8/decode (JSON, nlohmann-serialized, valid UTF-8)
wsdict: granolasdr:ft8:heard:CALL (TTL 900 s)
js8.cc — Epoch Decoder CPU thread (--js8/--js8-fast/--js8-slow/--js8-turbo/--js8-ultra) gm/hf/js8.cc · ft8_lib/
1 LDPC decode: BP decoder
(174,87) code M=87 · CRC-12 check
2 JSC decompress + frame decode:
Normal/Compact/Ultra/Turbo · extracts from_call, message text, APRS
3 Per-epoch dedup: seen_this_epoch_ cleared on 15s/10s/30s rollover
4 ZMQ: topic js8/decode (JSON)
wsdict: granolasdr:js8:heard:CALL (TTL 900 s)
ZMQ proxy XSUB:5599 ← producers | XPUB:5600 → consumers · wsdict:8765 → browser
ZMQ Proxy Bus + wsdict + PSKReporter proxy thread + Rust wsserver + Python HFRx.cc · wsserver/ · psk_uploader.py
1 ZMQ XSUB :5599 ← FT8, JS8 connect here
2 ZMQ XPUB :5600 → psk_uploader.py and any other subscriber
3 wsdict :8765 — browser WebSocket:
waterfall RGBA, ft8:heard:*, js8:heard:*, audio:status:*, audio:cmd
4 Audio ZMQ PUB :5581–5584 → audio_router.py (48 kHz PCM)
5 psk_uploader.py: subscribes :5600
ft8/decode + js8/decode topics
per-band best-SNR dedup · IPFIX UDP → pskreporter.info:4739 every 5 min
